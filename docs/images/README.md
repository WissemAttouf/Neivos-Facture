# Captures d’écran — Neivos Facture

Déposez dans ce dossier les captures d’écran réelles de l’application **Neivos Facture**.

Noms de fichiers conseillés :
- `accueil.png` — tableau de bord ou écran d’accueil
- `factures.png` — liste des factures
- `details-facture.png` — détail d’une facture
- `creation-facture.png` — création ou modification d’une facture

Après avoir ajouté les images, leurs chemins pourront être référencés dans le README principal, par exemple :

`![Tableau de bord de Neivos Facture](docs/images/accueil.png)`

Utilisez les noms exacts des fichiers lors de leur intégration au README.
